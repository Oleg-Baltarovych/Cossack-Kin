## 6. Gotchas / learned the hard way
_(append one line per non-obvious discovery: what, where, why)_
- Balance: with SPEC §3.2 numbers and no modifiers a greedy bot reaches bloom of village 1 in ~2.8 days (target 4–6) — see `SPEC-REVIEW.md` B-01. Do not trust the table until `balance-sim` exists.
- pnpm is not installed globally — enable via `corepack enable` at scaffold (Node 24 is installed).
- Windows dev machine: hooks are Node scripts (no bash/jq). Git Bash heredocs with quotes break — use the Write tool or script files.
- Headless Chromium needs WebGL enabled for canvas screenshots (check flags at M0); animations must be frozen (`?freeze`) for stable screenshots.
- Project agents/skills load only when the Claude Code session starts in this folder.
- Playwright agents were adapted from Playwright 1.65.1 output; after a major upgrade re-run `npx playwright init-agents --loop=claude`, then re-apply the short descriptions, `tests/e2e/` paths and the "Game-specific notes" block.

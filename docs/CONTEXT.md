- Building life (M2-11): a prop/TierPart `smoke: { dx, lift }` = its chimney mouth px (read off the frame; `gen-life.test.ts` holds each vent on an opaque px with open air above, per tier) → the Fx layer (graded, parallax 1) draws `QUALITY_TIERS[q].smoke` puffs per shown chimney (`smokePuffs`, `SMOKE` in config.ts: lean/flatten from the wind; claimed as particles); «менше руху» = `stillPlume` (3 fixed puffs, not particles). - Pixi v8 batches several textures per draw call (up to `MAX_TEXTURE_IMAGE_UNITS`, `batcher/gl/utils/maxRecommendedTextures`): interleaving sprites of 2 atlases in one Y-sorted container measured +0 draw calls (M2-01).

- Time of day (ART-04): `dayCycle(minutes)` → keyA/keyB/t (smoothstep over each key's transition; night holds 23:00–04:00) + sun/moon. The visible sun stays in the left 40 % by art convention (sprites lit top-left), x follows altitude only (`SUN_X_*`). The sky is not graded (it is the light source); the `ColorMapFilter` sits on a `graded` container (clouds…fx) inside the world; emissive and the dev swatch are post-grade. Draw calls with the scene: sky 1 + graded 2 + post-grade 1 + upscale 1 = 5.
- `BufferImageSource` with a `Uint8Array` defaults to `bgra8unorm` — pass `format: 'rgba8unorm'`. `ColorMapFilter.destroy()` also destroys its LUT texture. LUTs are decoded on the main thread with `createImageBitmap(blob, { premultiplyAlpha: 'none', colorSpaceConversion: 'none' })` + OffscreenCanvas `getImageData` (CSP-safe, byte-exact). `pnpm luts` runs wherever `pnpm sprites` does (dev, build, e2e webServer, CI).
- LUT generator (`assets-src/luts/gen.ts`) and generators: only + − × ÷, `Math.round`, `Math.sqrt` — no `**`/`Math.pow`/trig in output (engine-dependent bits). Recipe parts are composed with `{ light: false, occlusion: false }` (recipes place every shade). Declare `Material` members as function properties (`base: (f) => …`), not methods (typescript-eslint `unbound-method`).
- Sky dither: fraction quantized to quarters (only 25/50/75 % Bayer patterns), soft fbm "air streaks" per key; the lightest chain color is reserved for the sun/moon disc. Night ground constraints (art-director): top band ≤ `cloth 1`, darker than the `cloth 2` horizon, ≥ `ink 2` — leaves ~12 luma levels for the M0 bands (unit-tested in `tests/unit/tools/luts.test.ts`).

Scene-wide checks are scoped: "never black" only on dark keys (0530/2100/2300); "sky on palette" only above the highest cloud (clouds are LUT-graded). `waitReady` allows 20 s (SwiftShader first frame under parallel workers).

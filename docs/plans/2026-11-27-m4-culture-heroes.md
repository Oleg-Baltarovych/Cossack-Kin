## 0. Ключові рішення (архітектура; продуктові розвилки — §6)
- **Джерела модифікаторів (новий шар, ADR 013):** `modifierSources(state): readonly ModSource[]`, `ModSource = { field: ModField; source: SourceRef; share: number }` (`SourceRef` — union `sich | farm | relic | culture | hero | passive | defence`). `collectModifiers` = згортка джерел (`1 + Σ share` для «+», `1 − Σ share` для «−» з мінімумом у контенті) × вітер моменту. Тоді UI-підказка й економіка — одне й те саме за побудовою. Спершу — рефактор без зміни поведінки (звіт балансу байт у байт). Кешу нема, доки заміри не покажуть потреби (§9.6).
- **Нове поле `Modifiers`:** лише `cultureCostMult` (Кобзар, «Кобза діда»). Решта ефектів M4 лягає в наявні поля: `incomeMult`, `buildingMult` (харчові), `costMult`, `gloryMult`, `powerMult`, `offlineMult`, `offlineCapSec` (стеля `OFFLINE.maxCapSec` 24 год), `gloryCapSec`, `lootMult`, `relicChanceMult`, `raidTimeMult`. Ефект вузла/героя — `{ kind: ModField; perRank }` 1:1 до поля (як реліквії M3-06).
- **Контент:** `content/culture.ts` (`CULTURE_BRANCHES` з умовою відкриття; `CULTURE_NODES`: `id`, `branch`, `row` 1–4 (корінь, 2, 2, вершина), `requires` (будь-який вузол попереднього ряду ранг ≥ 1 / конкретні id), `maxRank`, `base`, `growth`, `effects[]`), `content/heroes.ts` (`HEROES`: `id`, `unlockBeat`, `levelMax` 25, `base`, `growth`, `effects[]`, `agent`). Ціна: `base × growth^rank × cultureCostMult` (слава, Big). Ids лише дописуються (як справи).
- **Відкриття — похідне, не стан:** гілка «Музика» — шинок ≥ 1; «Звичаї» — церква відкрита (віха «Освячення Покрови») (Q4); герой — побачена віха з нагородою `{ kind: 'unlock'; hero }` (§2.5 тип уже передбачає). Прихід героя = рівень 1 безкоштовно (Q6). Ефекти рахуються лише для відкритих (як закриті будівлі Січі: крафтований сейв нічого не дає).
- **GameState v5** (`/save-migration`, `004-v4-to-v5.ts`, фікстура `v5.json` з `capture-save`):
  ```ts
  version: 5;
  culture: Readonly<Partial<Record<CultureNodeId, number>>>;  // ранг 1..maxRank; нема = 0; невідомий id відкидається
  heroes: Readonly<Partial<Record<HeroId, number>>>;          // рівень 1..levelMax; нема = ще не прийшов
  stats: { …v4; cultureRanks: number; heroLevels: number };   // монотонні лічильники для справ/ланцюжка
  ```
  Розріджені записи → нові вузли й герої M5+/M10+ без bump. Гейт: ранг/рівень у межах контенту, невідомий id відкидається (rename-safe, як `story.seen`), `cultureRanks ≥ Σ рангів`, `heroLevels ≥ Σ (рівень − 1)`; передумови й відкриття не перевіряє (похідні; формули на них не покладаються). Походи: `returnAt = startedAt + round(durationMs × raidTimeMult)`, гейт — діапазон `[ceil(durMs × RAIDS.minTimeMult), durMs]` (0.75; контент-тест: максимум Σ джерел `raidTime` ≤ 1 − `minTimeMult`). Міграція: `culture` {}, `heroes` = { герой: 1 } для кожної вже побаченої віхи-відкриття (інакше герой недосяжний), лічильники 0, ланцюжок — Q12.
- **Дії:** `buyCulture { id }` (один ранг; відмови `locked` гілка, `prereq`, `max`, `glory`), `levelHero { id, mode }` (спільний перемикач ×1/×10/×25/Макс; `locked`, `max`, `glory`). Події `CultureBought { id, from, to }`, `HeroJoined { id }` (з віхи — може прийти з офлайну, як `StoryBeatReached`), `HeroLevelled { id, from, to }` (лише з дії).
- **Характерник у походах:** `raidTimeMult` (steady) застосовується в `rollRaid` на старті й у прев'ю (`durationSec` картки, «повернуться о…»); здобич від часу не залежить; походи в дорозі не змінюються (Q8). `relicChanceMult` += частка героя.
- **Рендер (лише події + селектор `heroesSceneView`):** отаман — як є; Кобзар-герой сидить біля шинку вдень (`play` 4@6, атлас уже має), уночі — біля вогнища Січі; мандрівник-кобзар у ці слоти не виходить (розклад core не змінюється, рендер пропускає слот); Характерник — новий спрайт `kharakternyk.a` у Січі (Q10). Поява — на `HeroJoined` наживо (виходить із брами / дверей куреня), з офлайну — уже на місці.
- **UI:** вкладка **Культура** (між «Січ» і «Ще», камера не їде — зони нема, ADR 011): угорі блок «Герої» (3 картки: портрет-спрайт ×2, ім'я, рівень, ефект зараз → після, ціна; закритий — силует і «Прийде, коли…»), нижче дві гілки деревом (корінь → 2 → 2 → вершина) з лініями передумов; тап по вузлу — липка картка внизу (ефект за ранги, «зараз → після», факт-тултіп §16, «Вивчити»). Підказки бафів: тап по HUD (дохід, слава, сила) і по рядку «Офлайн-ліміт» на «Ще» → `ModifierBreakdown` (джерела з частками). Червона крапка на «Культура» — лише коли з'явився новий доступний і досяжний вузол рангу 0 або щойно прийшов герой (Q13).
- **Квести:** `BUILD_SYSTEMS` += `'culture'`; `StatId` += `cultureRanks`, `heroLevels`; справи «Вивчи ранг культури», «Підвищ героя» (append, `requires: 'culture'`, пропонуються лише коли є що купити — як `raidReady`); крок ланцюжка — Q12.

| # | Патерн жанру | Типова слабкість | Як робимо (→ задача) |
|---|---|---|---|
| П1 | Дерево з передумовами | вузли видно лише після покупки — «сліпий» вибір | усе дерево видно одразу: закриті вузли з ефектом і умовою; гілка закрита — з поясненням, коли відкриється → M4-13 |
| П2 | Респек | без респеку = страх зіпсувати білд; з респеком = рутина | вибори **не взаємовиключні** (кожен вузол рано чи пізно купується, лише позитивні ефекти), тож респек не потрібен і його нема; вузли — постійні, переходять через переселення (§3.6) → M4-02 |
| П3 | Прихований стек множників | «+10 %» не видно, до чого; множники множаться непрозоро | одне правило §9.6 (у полі додається, між полями множиться) + `modifierBreakdown`: тап по числу → усі джерела з частками; тест «сума джерел = поле» → M4-03, M4-07, M4-14 |
| П4 | Прев'ю покупки | лише «+5 %» без контексту | «+8 % → +12 % доходу · +1,2тис./с» — відносне **й** абсолютне від core-селектора; для часу — «4 год → 3 год 48 хв» → M4-07, M4-13 |
| П5 | Прокачка героя з віхами-стрибками | розпорошення валюти між героями (пастка новачка) | лінійний ефект, видима стеля рівня (25 у M4), спільний ×1/×10/Макс; герой приходить з рівнем 1 і одразу щось дає → M4-05, M4-12 |
| П6 | Скорочення таймерів | ретроактивна зміна таймерів у дорозі ламає відлік і довіру | Характерник діє на нові походи; картка показує «−5 % · Характерник»; час фіксується на старті (як здобич, ADR 012) → M4-06 |
| П7 | Онбординг системи | нова вкладка без пояснення | віха «Рада на майдані» (модалка з отаманом) → кнопка «До героя»; перший вузол — дешевий і з одним кроком ланцюжка (Q12) → M4-08, M4-16 |
| П8 | Червоні крапки | крапка на кожну доступну покупку = шум | крапка лише на **нове** (вузол рангу 0 став досяжним, герой прийшов), не на кожен ранг → M4-07 |

Свідомо **не** беремо: респек за писанки, випадкові «таланти», гачу героїв, тимчасові бафи культури з таймером, рекламу за культуру.

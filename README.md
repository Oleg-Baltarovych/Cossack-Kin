# Козацький хутір · Cossack Kin: Idle Village

An atmospheric pixel-art idle game for mobile: revive a Cossack settlement on the Dnipro, grow the household,
send Cossacks on raids, develop culture and move your kin from land to land — under living skies with weather,
light shafts and a real day–night cycle.

> Status: design phase — specification, review and AI-assisted workflow. No game code yet.
